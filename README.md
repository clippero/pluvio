
# 🌧️ PluvioTrack - Registro de Lluvia con IA

Aplicación de monitoreo meteorológico de alta precisión diseñada para Android. Utiliza **Google Gemini AI** con **Google Search Grounding** para obtener datos en tiempo real sobre la precipitación caída en tu geolocalización exacta.

## 🚀 Características
- **GPS en Tiempo Real**: Detecta automáticamente tu ubicación para darte el dato exacto de tu zona.
- **Análisis con IA**: Resúmenes inteligentes sobre el estado hídrico del suelo.
- **Gráficos Dinámicos**: Visualiza la tendencia de los últimos 7 días.
- **PWA Ready**: Instálala en tu Android como una aplicación nativa (sin pasar por la Play Store).
- **Modo Oscuro Premium**: Estética Glassmorphism optimizada para pantallas OLED.

## 📲 Instalación en Android (PWA)
1. Abre el link de GitHub Pages en **Google Chrome**.
2. Acepta los permisos de **Ubicación**.
3. Toca los tres puntos (`⋮`) de la esquina superior derecha.
4. Selecciona **"Instalar aplicación"** o **"Añadir a la pantalla de inicio"**.
5. ¡Listo! Ya tienes el icono de PluvioTrack en tu escritorio.

## 🛠️ Tecnologías
- **React 19** + **Tailwind CSS**
- **Google Gemini API** (Model: gemini-3-pro-preview)
- **Recharts** para visualización de datos.
- **Vercel/GitHub Pages** para hosting estático.
